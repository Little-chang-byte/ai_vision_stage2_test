# 参考资料与自主设计

实际查阅了三阶段思维导图原图、项目第二阶段源码和结果，以及 Redis 官方 Windows 安装文档 https://redis.io/docs/latest/operate/oss_and_stack/install/archive/install-redis/install-redis-on-windows/ 。后者确认 Windows 的 WSL、Docker 或 Memurai 运行路径，需要对应运行环境。

项目复用原 YOLO 和 Ollama 调用，不替换算法。自主集成工作包括 JWT 保护任务图片、哈希输入绑定、独立模型状态、有效结果比较、历史和刷新恢复、SQLAlchemy 备注/确认删除、任务投递保护和可重复的真实浏览器证据脚本。这些是本项目集成设计，不主张算法原创性。

README 和 Linux 指南引用的 Docker、Ollama 文档是未来部署操作入口。Linux 命令尚未实测，不虚构使用经验或部署成果。
