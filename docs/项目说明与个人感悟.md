# 项目说明与个人感悟初稿

本项目将第二阶段 YOLO11n 和 Qwen3-VL 同图比较集成为本机 Web 应用。FastAPI 提供认证上传、任务、图片和历史接口；SQLAlchemy 使用 SQLite 保存输出和错误；原生 HTML/JavaScript 完成输入与并排展示；Celery/Redis 提供队列实现。当前真实六图浏览器验证运行于显式 local 模式，Redis 实际服务与 Linux Docker 待验证。

相较第二阶段，增加图片哈希绑定、模型返回校验、独立状态和错误、数据库历史、备注与确认删除、JWT 保护图片，以及可复现的浏览器录屏脚本。真实模型可能分类错误，界面展示的是模型实际结果。

学习过程初稿 [待本人确认]：通过本阶段可以理解模型能力、Web 服务和任务调度之间的关系。实际排查的问题包括缺失测试字段导致假阳性、测试污染正式数据库、包导入错误、VLM 思考耗尽输出预算、JWT 主体校验和本机 Redis 环境缺失。已通过隔离测试及浏览器真实模型运行验证部分解决方式。
