# 模型调用流程

浏览器上传真实图片，API 验证可解码格式并计算 SHA-256。任务创建必须提交该哈希；服务器再检查文件内容与哈希文件名，任务执行前每个模型再读取校验。

YOLO 使用原 yolo11n.pt 和原 conf=0.25，预处理由 Ultralytics 原流程执行，返回每个对象的置信度与 bbox，计数按对象类别累加。结果图是真实 result.save 输出。

VLM 对同一文件原字节 Base64 编码，Ollama /api/chat 传递图片，qwen3-vl:4b 返回 content 和可能的 thinking。只解析 content，要求完整 JSON、有效对象和完成状态。真实模型忽略 think=false 时仍可能耗尽预算，因此统一提高预算至 4000，并保留失败/重试和 raw。

Web 先保存原始返回再校验，两个结果独立。成功对象进入 comparison_result。页面经认证接口读取 SQLite JSON 和检测框图片，显示原始类别、数量和耗时，不伪造或手工纠正模型识别。
