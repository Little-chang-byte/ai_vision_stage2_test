# 关键代码导读

- src/traditional_pipeline.py 的 YoloDetector.detect 输入文件路径、任务 ID 与输出目录，返回模型名、objects、counts、confidence、bbox、耗时；validate_yolo_result 检查数量与结构。
- src/vlm_pipeline.py 的 request 读取 Ollama URL、预算、超时，传递原图片 Base64；run_vlm 有限重试，保存每次 raw；validate_result_record 拒绝无效结果。
- src/web_app.py 的 Task 是 SQLAlchemy 表；upload 验图与哈希命名；compare 验证实际文件、请求哈希，入库后投递队列；run_task 串行调用两种模型并独立保存状态，失败模型不进入正常计数；task_image 保护图片范围；update_note 和 delete_task 实践更新与删除。
- src/queue_app.py 的 execute_task 是 Celery 工作流入口；mark_interrupted 是管理员确认 worker 停止后的状态修复，不执行模型。
- frontend/index.html 用 JWT 请求受保护接口，以 Blob 展示图片，轮询终止后恢复按钮，localStorage 保存任务 ID，sessionStorage 保存登录 Token。
- scripts/real_web_regression.py 启动独立数据库与临时凭据，经真实浏览器输入图片，保存录屏截图和 summary；不替代 Redis/Celery 集成测试。
- tests/test_web_api.py 使用临时目录与完整模型 Fixture，验证最终数据库状态、比较内容和异常。原 VLM 测试继续验证累加、别名、校验与 CLI 对比。
