# 答辩问题
1. YOLO 与分类：YOLO 输出类别和位置，分类通常只输出整图类别。
2. 边界框：包围目标的矩形坐标。
3. 置信度：模型对检测结果的可信程度。
4. 同图：控制输入变量，保证公平比较。
5. 多模态模型：可处理图片和文本等多种输入。
6. Attention：按上下文分配 token 相关性权重。
7. YOLO 适合固定类别、稳定定位和低延迟。
8. 大模型适合开放类别和自然语言解释。
9. 幻觉：模型可能生成图中不存在的内容，需约束并核验。
10. SAM 输出像素掩膜，YOLO 输出检测框和类别。
11. API 不可用时检查密钥、网络和模型名，不能用模拟结果冒充。
12. 当前项目应通过同一图片重新运行验证修改。
